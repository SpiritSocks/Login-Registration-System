# Login-Registration-System
This is my Login &amp; Registration system project in C++
You can create accounts, and login to the ones that are already created.

_______________________
Features:
1. Account creation - you can create accounts, log into them or fail to login (you have 3 tries to enter the correct password)
2. Password protection - passwords saved to the database2.csv file are hashed (encrypted) using a "homemade" hash fucntion.
3. Simplicity - the program is easy to use
